### API 文档：玩家赛事记录 3. 创建玩家赛事记录
- URL: /api/PlayerMatches
- 方法: POST
- 描述: 创建一条新的玩家赛事记录。此操作通常需要管理员或赛事组织者权限，并且会进行多项业务逻辑验证，例如玩家和战队是否已报名赛事等。
- 认证: 需要用户认证 (JWT Token)，且用户需具备相应权限。
- 请求体 (Request Body): application/json
  
  ```
  {
      "playerId": 
      "guid-of-player", // 玩家ID
      "eventId": 
      "guid-of-event",   // 赛事ID
      "gameRoleId": 
      "guid-of-game-role", // 游戏
      角色ID
      "result": 
      "Win",              // 比赛结
      果，可选值: "Win", "Loss", 
      "Draw" (或中文 "胜利", "失败", 
      "平局")
      "score": 
      100,                 // 玩家
      得分
      "playedAt": 
      "2023-11-25T10:00:00Z" // 比
      赛时间 (可选，默认为当前时间)
  }
  ```
- 响应示例:
  
  ```
  {
      "id": 
      "guid-of-new-player-match",
      "playerId": "guid-of-player",
      "eventId": "guid-of-event",
      "gameRoleId": 
      "guid-of-game-role",
      "result": "Win",
      "score": 100,
      "playedAt": 
      "2023-11-25T10:00:00Z",
      "createdAt": 
      "2023-11-25T10:00:00Z",
      "updatedAt": 
      "2023-11-25T10:00:00Z",
      "eventName": "某某杯赛事",
      "gameRoleName": "上单"
  }
  ```
- 可能的状态码:
  
  - 201 Created : 赛事记录创建成功。
  - 400 Bad Request : 请求参数无效或不符合业务逻辑 (例如：玩家不存在、战队未报名赛事、赛事队伍不足等)。
  - 401 Unauthorized : 用户未认证。
  - 403 Forbidden : 用户无权限执行此操作。
